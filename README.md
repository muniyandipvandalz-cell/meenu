# Meenu ❤️ 💍 — Interactive Marriage Proposal Website

A minimal, dreamy, cinematic romantic interactive marriage proposal website built for **Meenu ❤️** ("Will you marry me?"), featuring mobile-first design, infinite spring-dodging NO button, and romantic instrumental music.

---

## 💍 Highlights & Features

- **Personalized for Meenu ❤️**:
  - Main question: **"Will you marry me?"** 💍
  - Subtitle: *"In a world of billions, my heart chose you. Forever and always."*
- **Interactive Infinite NO Button**:
  - Playfully dodges cursor on desktop and touch on mobile devices.
  - Pleading & playful marriage-themed messages (*"Think of the cake! 🎂"*, *"Look at the ring! 💍"*, *"Destiny says YES! ✨"*).
  - Strictly clamped within viewport boundaries.
- **YES Celebration**:
  - Golden-rose confetti fireworks, floating hearts and diamond rings.
  - Final screen: **"She said YES! 💍❤️"** & *"Forever begins today."*
- **Background Music**:
  - Built-in romantic piano/harp Canon in D arpeggios that play offline without external dependencies.
- **Mobile First**:
  - Full dynamic height (`100dvh`), tactile haptic feedback, safe area support.

---

## 🚀 Running Locally

```bash
npm install
npm run dev
```
Open [http://localhost:3001](http://localhost:3001) in your browser.

---

## 📦 Building for Production

```bash
npm run build
```
The output files are generated in `dist/`.
